Heart Disease Prediction System
Overview
This project is a Machine Learning-based application that predicts
the possibility of heart disease using patient health parameters. 
It features a user-friendly Tkinter GUI where users can enter 
medical details and receive an instant prediction generated by a trained 
Random Forest model.

Features
Predicts the possibility of heart disease
User-friendly Tkinter graphical interface
Instant prediction using a trained Random Forest model
Simple and easy-to-use application

Technologies Used
Python | Pandas | NumPy | Scikit-learn | Tkinter | Joblib

Dataset
The model is trained using a Heart Disease dataset containing patient 
health attributes such as age, sex, chest pain type, resting blood pressure, 
cholesterol,asting blood sugar, ECG results, maximum heart rate, exercise-induced angina, oldpeak, slope, ca, and thal.

How to Run
Clone this repository.
Install the required libraries.
Run the Python application.
Enter the patient details.
Click Predict to view the prediction result.

Output
The application displays one of the following results:
No Heart Diseases
Possibility of Heart Diseases
